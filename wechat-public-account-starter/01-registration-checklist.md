# 01 注册与后台设置清单

## 注册前准备

- [ ] 一个未注册过公众号的邮箱。
- [ ] 本人微信号。
- [ ] 本人手机号。
- [ ] 身份证信息。
- [ ] 3-5 个备选公众号名称。
- [ ] 1 张清晰头像或简洁文字标识。
- [ ] 公众号简介一句话。

## 注册路径

1. 电脑打开微信公众平台：https://mp.weixin.qq.com/
2. 点击注册。
3. 账号类型选择“订阅号”。
4. 主体类型选择“个人”。
5. 完成邮箱验证、身份信息填写、运营者微信绑定。
6. 登录后台，补全头像、名称、简介等信息。

## 账号基础配置

- [ ] 公众号名称：知识经验类，避免太商业化或太窄。
- [ ] 头像：头像清晰，缩小后仍能识别。
- [ ] 简介：说明“你帮谁解决什么问题”。
- [ ] 自动回复：欢迎语 + 内容方向 + 关键词引导。
- [ ] 菜单或合集：优先放“精选文章”“关于我”“联系我/合作”。

## 注册完成检查

- [ ] 能正常登录公众号后台。
- [ ] 主体信息无误。
- [ ] 运营者微信绑定成功。
- [ ] 名称、头像、简介完整。
- [ ] 手机端搜索或预览显示正常。

## 名称判断标准

好名称应该满足：

- 容易读、容易记、容易搜索。
- 不承诺夸张结果。
- 不把方向锁死到一个很窄的工具或热点。
- 未来 1-2 年仍然能继续使用。

建议格式：

- `个人识别点 + 领域`：阿X的AI笔记、张三的效率实验室。
- `人群 + 价值`：普通人的成长笔记、打工人的工具箱。
- `风格 + 主题`：认真一点的效率课、少走弯路笔记。
