# 04 文章写作模板

## 标题模板

- 我用 X 解决了 Y 问题。
- 普通人如何用 X 做到 Y。
- 试了 X 天后，我发现 Y 最有用。
- 不知道怎么 Y？可以先试试这个方法。
- 这不是最厉害的方法，但适合普通人开始。

## 正文模板

### 1. 痛点开头

用 3-5 句话说清楚读者遇到的问题。

示例：

> 很多人不是不想提高效率，而是不知道从哪里开始。工具越来越多，方法越来越复杂，最后反而什么都没坚持下来。我最近试了一个很简单的做法，虽然不花哨，但真的能降低开始行动的阻力。

### 2. 我的真实场景

说明你为什么遇到这个问题，以及你原本怎么做。

要写具体，不要只写观点：

- 我在哪个场景遇到这个问题？
- 原来的做法有什么麻烦？
- 我为什么决定试这个方法？

### 3. 具体方法

按步骤写，最多 3-5 步。

推荐结构：

1. 准备什么。
2. 第一步做什么。
3. 第二步做什么。
4. 怎么判断有没有效果。
5. 不适合什么情况。

### 4. 一个例子

给出一个完整例子，让读者能照着做。

例子要包括：

- 输入：原始问题或素材。
- 过程：你怎么处理。
- 输出：最后得到什么。
- 结果：节省了什么，改善了什么。

### 5. 注意事项

写 2-3 条限制，避免内容显得夸张。

示例：

- 这个方法适合快速开始，不适合追求完美方案。
- 工具只能帮你整理，最终判断还要靠自己。
- 如果任务本身目标不清楚，先不要急着找工具。

### 6. 结尾互动

用一个具体问题收尾。

示例：

> 你现在最想用 AI 或效率方法解决哪个问题？可以留言告诉我，我会从里面选题继续实测。

## 发布前检查

- [ ] 标题能让读者知道看完有什么收获。
- [ ] 开头 200 字内说清楚痛点。
- [ ] 每个方法都有具体步骤。
- [ ] 至少有一个真实例子。
- [ ] 结尾有明确提问。
- [ ] 手机端预览排版正常。
- [ ] 没有夸张承诺和虚假数据。
